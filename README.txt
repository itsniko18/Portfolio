NIKKON SENGUPTA - DESIGN PORTFOLIO
====================================

HOW TO VIEW THE WEBSITE:
-----------------------
Option 1 (Direct in Browser):
Double-click on "index.html" to open the website directly in Google Chrome, Microsoft Edge, Safari, or any web browser.

Option 2 (Local Web Server):
Double-click "start_server.bat" (requires Node.js installed).
It will automatically start the server and open http://localhost:5173 in your default browser.

Or via terminal:
1. Open terminal in this folder
2. Run: node server.js
3. Open http://localhost:5173 in your browser
